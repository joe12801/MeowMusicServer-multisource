导入网易云歌单

粘贴歌单链接（https://music.163.com/playlist?id=3778678）或纯数字 ID。只取歌名/歌手，播放仍走多源回退，不受版权限制。
导入只加歌，不动原有内容；重复的歌会自动跳过。

自动同步任务

每天 05:00 把源歌单的新歌补进本地歌单；服务重启后会补跑一次。

外部音源（YouTube）

国内被下架、被禁的歌（例如 Beyond《长城》），酷我/网易云里只剩 DJ 版和翻唱。 配上 mp3.994938.xyz 的 KEY 之后，搜索会把 YouTube 上的原曲排到前面， 音频由服务器转码后回源，KEY 不会出现在浏览器或设备里。 首次播放要等 10~20 秒（对方现下现转），之后同一首秒开。

KEY 保存在 data/files/settings.json（0600），保存后立即生效，不用重启。 环境变量 MUSIC_MP3API_KEY 已配置时以它为准。

歌词源（LrcAPI）

额外一路歌词来源：github.com/hisatri/lrcapi，背后是 Apple Music 的逐字歌词 + 酷狗聚合。 只在 LRCLIB 和网易云都没收录时才去问它（冷门歌、动画 OST、翻唱、被下架的版本）， 正常播放不会多等一次请求。
读取中…
默认公共实例 https://api.lrc.cx；自建填 http://lrcapi:28883（同 Docker 网络里直接用容器名）。 保存后立即生效，缓存里已有的歌词不受影响。环境变量 LRCAPI_BASE 优先于这里。

汽水音乐（抖音曲库）
